# FakeStore App

A React e-commerce practice application built with Vite, React Router, Axios, React-Bootstrap, and FakeStoreAPI.

## Features

- Browse products from FakeStoreAPI
- View individual product details with dynamic routes
- Add a product with a POST request
- Edit a product with a PUT request
- Delete a product with a confirmation modal and DELETE request
- Responsive navigation with React Router and React-Bootstrap
- Loading and error states for API requests

## Run locally

```bash
npm install
npm run dev
```

Open the local URL displayed by Vite, usually `http://localhost:5173`.

## Technologies

- React
- Vite
- React Router DOM
- Axios
- React-Bootstrap
- Bootstrap
- FakeStoreAPI

## Note

FakeStoreAPI is a mock API. Successful create, update, and delete requests demonstrate the request workflow but do not permanently modify the API data.
